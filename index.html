HTML quick reference

Every HTML input type, explained.

Explore all 22 values of the <input type> attribute, see them in action, and learn when each one is useful.

Try the examples. These controls are real browser inputs. The examples are for learning; they are not wrapped in a form that submits data. Use labels in your own forms, validate important values on the server, and give every control an accessible name.

All 22 input types

text

Single-line, general-purpose text. Use for names, titles, and values without a more specific input type.

password

Conceals typed characters on screen. Use for passwords; always transmit securely and handle authentication on the server.

email

For one or more email addresses. Enables email-friendly keyboards on mobile and supports built-in format checks.

search

Text field for search queries. Browsers may add a clear control or apply search-specific keyboard behavior.

tel

For telephone numbers. No universal number format is enforced, so apply the format your service expects.

url

For a web address. Browsers can check that the value is a valid URL before form submission.

number

For numeric values where a spinbutton makes sense, such as a quantity. Set appropriate min, max, and step.

range

For choosing an approximate value within a range, like volume or brightness—not an exact numeric entry.

date

For a calendar date (year, month, and day) with no time or time zone.

time

For a time of day, such as a meeting time. It does not represent a date or time zone.

datetime-local

For a local date and time with no time-zone information, such as scheduling in the user's own locale.

month

For selecting a month and year, such as a reporting period or card expiry month.

week

For selecting a numbered calendar week and year, useful for weekly schedules and reports.

checkbox

For an independent yes/no choice or multiple selections from a list. A checkbox can be checked or unchecked.

radio

Preferred contact method

For exactly one choice from a small group. Give related radio buttons the same name.

file

For selecting files from the device. Use accept to guide selection; verify file type and size on the server too.

color

For choosing a color, often for themes, drawing tools, or visual customization.

submit

Submits its containing form. Use as the primary action after the user has completed the form.

reset

Resets controls in its containing form to their initial values. Use sparingly because it can erase user work.

button

A generic button with no built-in action. Use JavaScript for actions that are not submitting or resetting a form.

image

Image submit (inside a form)

An image-based form submit button. Provide alternative text; coordinates of the click are submitted too.

hidden

No visible control (inspect the markup)

Hidden value: form-version=guide-v1

Stores a value submitted with a form without displaying a control. It is not secure—users can inspect and change it.

Quick use-case reference

TypeBest forHelpful detail
text, search, email, tel, url, passwordEntering text with different intentChoose the most specific type to improve mobile keyboards and browser validation.
number, rangeNumeric valuesUse number for precise entry; use range for approximate slider input.
date, time, datetime-local, month, weekCalendar and clock valuesSupport and appearance vary by browser and operating system.
checkbox, radioBoolean settings and choicesCheckboxes allow independent/multiple choices; radios allow one choice per shared name.
file, colorPicking a local file or a colorCheck uploads on the server; provide a color fallback if color precision matters.
button, submit, reset, imageActions within or alongside formsUse submit for saving, button for custom actions, and reset only when clearing is intentional.
hiddenNon-visible form metadataNever use as a place to store secrets or trusted authorization data.
